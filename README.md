# Project Tab

Project Tab 是一个 Chrome / Edge Manifest V3 扩展，用独立的数据模型管理网页项目和标签页。它不调用 `chrome.bookmarks`，项目标签页不会写入浏览器收藏夹。

## 本地加载

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展”，选择本目录 `/Users/nutcracker/Myapp/projecttab`。
4. 点击工具栏图标，在弹出面板中把当前页面添加到项目；点击“打开主面板”进入项目侧边栏。

## 功能入口

- 主面板右上角文件夹加号：在项目列表顶部直接输入名称并创建项目，不打开浏览器对话框。
- 项目右侧 `+`：打开浏览器历史记录，多选后批量添加。
- 项目右侧铅笔：进入管理状态；每个标签页右侧显示删除按钮，也可批量移动、复制或删除。
- 项目右侧三点菜单：创建子文件夹、重命名、归档/恢复或删除项目；归档项目会移到列表底部的“已归档”区域，删除使用面板内确认框。
- 标签页星标：标记重要页面；笔记图标：记录文字、链接和图片。
- 页面标记：在网页中选中文字，浮出工具条选择 6 种颜色高亮，或点击“评论”高亮并写下评论/笔记；点击页面上的高亮可再次编辑评论、换色或删除。标记随页面条目保存，关闭页面、重开浏览器都不会丢失，下次打开已收藏页面时自动还原高亮；从项目中删除该页面条目时，其上的标记一并删除。侧边栏标签页行显示“N 处标记”，点高亮图标可查看全部标记列表（编辑、删除、“打开并定位”）。未收藏的页面会先提示收藏后再标记。标记文本也会参与侧边栏搜索。
- 项目右侧 ✦：生成本地项目摘要、来源聚类、关键词和标签页关联，也可在设置中接入自定义 AI Endpoint；设置页提供 AI 模型连接测试。
- 主面板右上角同步按钮：执行一次双向同步（先合并远端与本地，再推送），按设置写入浏览器同步空间或 WebDAV。

设置中的边缘触发范围按网页高度计算：0% 是顶部，100% 是底部；例如设置为 20%–30% 后，鼠标靠近左侧且位于这段高度范围内才会打开面板。触发条宽度默认为 0px，视觉上隐藏，但页面最左侧保留 4px 的无形触发区域。
网页边缘触发面板的操作栏最右侧提供图钉和关闭按钮；点击图钉会切换到浏览器原生 Side Panel，让浏览器真正缩小网页视口形成分屏。原生 Side Panel 使用浏览器标题栏自带的固定与关闭控件，不重复显示扩展内按钮。
面板只保留搜索框下方的内容滚动区，顶部操作栏和搜索框不滚动。

## 数据与同步

本地数据存储在 `chrome.storage.local`，也支持导入/导出 JSON。浏览器同步使用 `chrome.storage.sync`；WebDAV 使用扩展后台请求 PUT / GET。WebDAV 地址可以填写专用文件地址，也可以填写目录地址；目录地址会自动使用其中的 `project-tab.json`。坚果云支持填写不带结尾斜杠的 `/dav/projecttab`，扩展会自动写入 `/dav/projecttab/project-tab.json`。设置页的“测试 WebDAV”会测试目录地址本身，并显示实际上传文件地址、HTTP 状态、DAV/Allow 响应头和服务器返回体；AI 设置提供模型连接测试，非 JSON、HTML 错误页和 SSE 响应会被分别诊断或兼容处理。图片笔记会以内嵌 data URL 保存，导出文件可能较大。

同步按条目级双向合并（类似 Zotero）执行：

- 双向同步先读取远端，再逐条合并：项目与标签页按各自 `updatedAt` 取较新一方，笔记按 `note.updatedAt` 取较新一方，设置按 `settings.updatedAt` 整体取较新一方；同一时间戳以远端为准，保证两台设备收敛、不会互相覆盖。
- 页面标记按 id 取并集、按各自 `updatedAt` 取较新一方；单条删除通过软删除标记（`deletedAt`，随数组保留 90 天）跨设备传播，不会被旧副本复活。
- 删除与跨项目移动通过墓碑（`deletions`，保留 90 天）传播：已删除的项目/标签页不会在另一台设备合并时复活，移动走的标签页只留在目标项目（标记随条目一起移动）。
- `browserTabId` 是本机浏览器句柄，不写入远端也不参与差异比较；`state.updatedAt` 是本地保存水位，同样不参与差异判断。
- 触发时机：主面板同步按钮、设置页“双向同步（合并）”、开启自动同步后的本地修改（约 10 秒去抖）、定时闹钟与浏览器启动；浏览器同步空间收到新版本时也会自动拉取合并。WebDAV 没有推送通知，另一台设备的修改会在本机产生修改、定时同步或手动同步时被拉取。
- 设置页的“上传 / 下载”按钮仍是单向整体覆盖，仅供强制对齐使用。

## 页面标记的局限

- 标记只在主框架的 http/https 页面生效（与边缘面板一致）；`chrome://` 等特殊页面不支持。
- 高亮使用 CSS Custom Highlight API 渲染，不修改页面 DOM；定位以“选中文字 + 前后文”为主、CSS 选择器兜底，页面小幅改版后通常仍可还原。
- 闭合 Shadow DOM 内的文字无法标记；页面大规模动态重排后个别标记可能暂时失锚（数据仍保留在标记列表中，页面恢复对应文字后会自动重新锚定）。
- 同一 URL 收藏在多个项目时，标记优先归属当前打开的浏览器标签对应的条目。
